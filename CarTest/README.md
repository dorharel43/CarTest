# CarTest – אפליקציית בדיקה למולטימדיה

אפליקציה שבודקת את יחידת המולטימדיה (Android 5.1) ומנסה לקבל התראות מאייפון דרך Bluetooth LE (ANCS).

## בנייה
הקובץ נבנה אוטומטית ב-GitHub Actions בכל העלאה. אחרי שהריצה מסתיימת (וי ירוק), הקובץ נמצא תחת Artifacts בשם `CarTest-apk`.

## בדיקה
1. מתקינים את `app-debug.apk` במולטימדיה.
2. באייפון מתקינים את האפליקציה החינמית **nRF Connect** מה-App Store.
3. במולטימדיה: פותחים "בדיקת רכב" ולוחצים "התחל חיבור לאייפון".
4. באייפון: nRF Connect ← Scanner ← מוצאים את המכשיר ← Connect.
5. מאשרים צימוד בשני המכשירים, ובאייפון מאשרים שיתוף התראות.
6. שולחים לעצמך הודעה בוואטסאפ ובודקים שהיא מופיעה על המסך.

## קבצים
- `AncsClient.java` – כל החיבור לאייפון וקריאת ההתראות
- `MainActivity.java` – המסך: נתוני מכשיר, כפתורים, יומן
- `.github/workflows/build.yml` – בניית ה-APK ב-GitHub
